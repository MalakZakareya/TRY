# Bahrain Regulations Knowledge Base

This folder contains verified Bahrain laws and regulations
used by the Analyze Document feature.

Rules:

- Only use authoritative Bahrain sources.
- Keep the original regulation text.
- Store the official source.
- Store the law or regulation name.
- Store the law number when available.
- Store the article or section number when available.
- Store publication and amendment information when available.
- Never add AI-generated laws or regulations.
- Unverified information must not be treated as an official regulation.
